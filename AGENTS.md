# Repository instructions

Start with [engineering principles](docs/principles/index.md), then read the
[architecture](docs/architecture/index.md),
[conventions](docs/conventions/index.md), and
[development](docs/development/index.md) indexes. Follow their links to read and
apply the documents relevant to the task before acting.

Before editing for a story, follow the
[Start a story](docs/development/release_cycle.md#start-a-story) workflow.
Verify the current branch against that workflow and report the verified branch
in your first implementation update, before making any edits.

Keep rules in their authoritative documents rather than duplicating them here.
Before reporting completion, follow the required
[completion gate](docs/development/verification.md#completion-gate), verify the
work against the applicable requirements, and report any unmet requirements or
blockers.
