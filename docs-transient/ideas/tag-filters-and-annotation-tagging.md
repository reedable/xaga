# Tag Filters Across Views and Direct Annotation Tagging

Tag selection could be orthogonal to the selected browsing view. Selecting a
Topic, Feed, or Site would establish the ItemList scope, and selecting tags would
further filter that scope rather than switch away from it. Tag filtering should
be available in any ItemList view, alongside the existing filters.

Also support assigning tags directly to Annotations, independently of tagging
their parent Entries/Articles. Annotation assignments should participate in tag
filtering where Annotations appear in ItemList.

Related ideas: [Tagging Beyond Entries](tagging-other-entities.md) and
[Annotation Inspector](annotation-inspector.md).
