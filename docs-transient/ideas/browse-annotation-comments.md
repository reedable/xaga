# View and scan annotation comments

Provide a better way to view and scan the notes/comments the user has left in
articles. Make the user's comments easy to browse, with the associated highlighted
passage and source article available for context.

Today, semantic search includes annotation comments, but the list's text filter
matches highlighted text rather than comments. Neither establishes a dedicated
workflow for scanning the user's own comments.

Explore how to present comments within an article and across articles, whether
to show only annotations with comments, and how comment-text filtering should
work. A comment-focused list makes comments easier to scan but needs enough
passage and article context to remain understandable; showing comments alongside
all highlights preserves context but may make the user's writing harder to find.
The presentation and filtering behavior remain open for refinement.
